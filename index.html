The narrative IS migrated. The module’s guide text exists only as a rendered Simplifier guide; it was discovered from an organization key and a module name, pinned to the published read-only version 2026.0.0, and harvested — 18 pages discovered, 18 harvested, 0 skipped — then mapped onto the module template’s fixed page set. German is the authored source language; the English default pages are machine translations marked TODO:REVIEW.

This preview was built locally with the pinned toolchain rather than by CI: the build depends on a locally rebuilt, snapshot-bearing de.einwilligungsmanagement@2.0.3-snapshots, which resolves only from a local FHIR package cache. Carrying that rebuild into CI is an open Gate-A decision in the migration report.
