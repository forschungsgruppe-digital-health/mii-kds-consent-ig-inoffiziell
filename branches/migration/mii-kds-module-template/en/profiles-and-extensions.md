### Profiles and Extensions

The Core Dataset specifications are based, wherever possible, on international standards and terminologies — in particular on the profiling work of the [AG Einwilligungsmanagement on FHIR Consent](https://ig.fhir.de/einwilligungsmanagement/stable/).

All elements of the Core Dataset, adapted to the details and requirements of the Medical Informatics Initiative's use cases, are described as FHIR StructureDefinitions. Why a FHIR profile had to be adapted is explained in prose on the respective profile page.

#### Mandatory / must-support elements

For elements marked **mandatory** or **must-support**, the corresponding [rules of the IPS](https://build.fhir.org/ig/HL7/fhir-ips/design.html#must-support) apply to this implementation guide as well. See also [Must Support](must-support.md).

#### Further relevant profiles

Besides [Consent](StructureDefinition-e0e166b4-0f77-478d-9062-de0034d98ce0.md), [Provenance](StructureDefinition-f675b1e8-9f3f-44e8-bb59-9681f78eb464.md) and [DocumentReference](StructureDefinition-56375452-bfa1-4111-af7c-5b5ba9a1857c.md), further profiles are relevant for handling consents and consent templates. They are taken over unchanged from the [Einwilligungsmanagement implementation guide](https://ig.fhir.de/einwilligungsmanagement/stable/Home.html).

The following profiles have to be supported when using this guide:

| | |
| :--- | :--- |
| [Organization](https://ig.fhir.de/einwilligungsmanagement/stable/Organization.html) | the responsible institution |
| [ResearchStudy](https://ig.fhir.de/einwilligungsmanagement/stable/ResearchStudy.html) | the research project |
| [Patient](https://ig.fhir.de/einwilligungsmanagement/stable/Patient.html) | the data subject (pseudonymised) |

If the Broad Consent is represented or queried via FHIR Questionnaires, the following profiles should be used in addition:

| | |
| :--- | :--- |
| [QuestionnaireResponse](https://ig.fhir.de/einwilligungsmanagement/stable/QuestionnaireResponse.html) | the completed consent |
| [QuestionnaireComposed](https://ig.fhir.de/einwilligungsmanagement/stable/QuestionnaireComposed.html) | the consent template (renderable) |
| [TemplateFrame](https://ig.fhir.de/einwilligungsmanagement/stable/TemplateFrame.html) | the consent template (structure definition) |
| [TemplateModule](https://ig.fhir.de/einwilligungsmanagement/stable/TemplateModule.html) | a consent module |
