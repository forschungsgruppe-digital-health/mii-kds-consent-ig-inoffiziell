Description of the Consent module

The MII CDS module Consent is a base module of the Core Dataset (CDS) of the Medical Informatics Initiative (MII). It builds on the published preliminary work of the MII Taskforce Consent Umsetzung.

For representing the MII Broad Consent, the module follows the FHIR R4 profiles of the AG Einwilligungsmanagement of the Interop-Forum for form data (Questionnaire, QuestionnaireResponse) and consents (Consent).

The module's focus is the operationalisation (enforcement) of the consent filled in by the patient, on the basis of the consent policies (consolidated with the MII AG Consent in December 2021).

Target audience

Implementers

Data Integration Centers (DIC), software developers and system architects building FHIR-based solutions.
→ see Profiles and Extensions and Guidance for Implementers.

Researchers

Scientists using MII data for medical research.
→ see Guidance for Researchers.
