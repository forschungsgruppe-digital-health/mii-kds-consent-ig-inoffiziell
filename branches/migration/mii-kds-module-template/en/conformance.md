## Conformance

### Technical implementation

This section describes the syntactic and semantic requirements for implementing the Consent module.

Search parameters are also defined, which the respective systems must implement when the FHIR RESTful API is used. In principle, logical AND and OR combinations of search parameters are supported.

The foundations and further detail on searching and on the FHIR RESTful API were being worked out in the base modules at the time this implementation guide was written, and may be added or refined at a later point.
