Basierend auf den
[Empfehlungen](https://ig.fhir.de/einwilligungsmanagement/stable/DocumentReference.html)
der AG Einwilligungsmanagement zielt das Profil *MIIConsentDocumentReference* auf
ein real existierendes Dokument mit Bezug zum Einwilligungsdokument ab.

Jedoch beschränkt auf Scans von Einwilligungsdokumenten im PDF-Format.
